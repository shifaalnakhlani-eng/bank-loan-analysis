# Bank Loan Report

Bank loan analysis project (SQL + dashboards) built on 38,576 loan records from 2021.

## Dashboard preview
![Summary](dashboards/Dashboard_1_Summary.png)
![Overview](dashboards/Dashboard_2_Overview.png)
![Details](dashboards/Dashboard_3_Details.png)

The dashboards were generated with Python from `data/financial_loan.csv`, using the course Tableau background layouts. MTD = December 2021, MoM compares December with November.

## Contents
- `dashboards/`: the 3 dashboard images (PNG) and a Word file with all three
- `docs/01_Problem_Statement.docx`: dashboard requirements (Summary, Overview, Details)
- `docs/02_Domain_Knowledge.docx`: how bank loans work and why banks analyse loan data
- `docs/03_Terminologies_in_Data.docx`: definitions of every field in the dataset
- `docs/04_Query_Document.docx`: all SQL (T-SQL) queries with results
- `tableau_backgrounds/`: blank dashboard background images (JPG) and a Word preview
- `data/`: `financial_loan.csv` and `financial_loan_data_excel.xlsx`
